## 实现内容

- O01：argv 执行器、依赖步骤、超时及进程组处理、有界输出、真实 Git HEAD 与干净检查；worker 验收及集成验收分离，绑定 run/role/attempt/taskRevision/SHA/planHash。控制器观察外部串行合并的实际结果，不执行 Git merge。失败持久阻断后续集成，必须显式重验当前集成 HEAD。
- O02：报告完整结构、规范化 JSON 哈希及身份检查；文件清单、tip 与祖先关系来自独立 Git 观察。JSON 接收通过不等于独立验收通过。
- O03/O07：派发前检查所有有效 worker 的写集、例外及串行资源组；glob 交集涵盖未来文件。验收检查真实变更路径，重命名两端均检查，并重验符号链接。支持 `*`、`**`、`?`，拒绝 bracket/brace 模式；这是协作范围门禁，不是文件系统沙箱。
- O04：`python3 scripts/threadweave.py next --repo . --run <id> [--observations <file>]` 输出只读建议；未知先核对、保护脏文件和未合入成果，阻断时建议显式重验；不发送、不重建、不删除。分支清理建议需要保留策略审查。可提供 observation maxAgeSeconds 检查陈旧观察；未声明时不声称已验证其新鲜度。
- O05：每 worker 默认最多返工 2 次；超限不改变领域状态、计数及活动修订，独立 audit.jsonl 记录拒绝；不自动替换。
- O17：根据写集、契约与可变工作区需求选择并行方式，保留一 worker 一 worktree；同步协议、模板及中英文 README。

旧状态仍可读取，旧字符串“验证成功”不能作为新验收证据。旧 run 未声明写集时保留兼容入口，不宣称它已通过新写集门禁。
