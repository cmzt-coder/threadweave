## P1：跨模块闭环（第一批）

- [x] **N01 外部动作共同约束**
  - 问题：unknown intent 可被再次 dispatch；aborted/停止中仍可派发；create_worker 缺前置检查。
  - 建议：创建、派发、返工、替换共用 run 阶段/授权/状态/停止标记/未决操作检查；pending/unknown 必须先核对。
  - 验收：aborted/failed/complete、停止中、未决派发、无效状态时外部调用数为零。

  - 进展（2026-11-12）：创建/派发共用 run 阶段、停止标记、未决 intent 检查；`resolve_dispatch` 收敛 unknown/pending；aborted/停止中/未决时外部调用为零。
- [x] **N02 历史 attempt 与有效 worker**
  - 问题：旧 cancelled attempt 阻塞新 attempt；A running 时 B 无法派发。
  - 建议：每个角色记录当前有效 attempt；团队门禁只检查有效花名册；首次派发持久化门禁记录。
  - 验收：A running 时 B 可派发；旧 attempt 保留时替代者可派发；同角色并发替换只有一个有效操作。

  - 进展：`_active_workers` 按角色选最大 attempt；旧 cancelled 不阻塞新 attempt；A running 时 B 可派发。
- [x] **N03 启动/停止证据绑定持久身份**
  - 问题：report 与 expected 互相一致但违背持久 worker 身份也能通过；旧停止证据可复用；精确 root 比较缺失（L13）。
  - 建议：从持久状态生成 expected；证据绑定身份、分支、基线、root、采集时间与活动轮次；返工/新活动使旧停止证明失效。
  - 验收：报告与 expected 一致但违背持久身份、不同 root、旧停止证明、未来时间均拒绝。

  - 进展：expected 从持久状态生成；强制 role/attempt/observedAt；精确 root 比较；stopActivityRevision 绑定活动轮次，rework 使旧停止证明失效。
- [x] **N04 状态保存可恢复**
  - 问题：写入失败后 memory revision 前进、磁盘未前进；目录 runId 不一致仍可保存；虚假完成态可落盘。
  - 建议：锁内基于最新状态创建候选副本，写入成功后替换内存；失败不消耗 revision；校验身份与完成态不变量。
  - 验收：底层写入失败后可重读恢复；旧快照仍拒绝；run 身份不一致和虚假完成不能落盘。

  - 进展：save 使用候选副本，写入成功后才更新 revision；runId 目录一致性校验；完成态要求 worker 全部 integrated/archived 且无 outstandingResources。
- [x] **N05 归档与 manifest 一起恢复**
  - 问题：manifest 读改写无锁；复制非原子；半成品触发 ArchiveConflict。
  - 建议：manifest 更新加锁；先复制临时文件、校验哈希后原子发布；区分半成品与已提交证据。
  - 验收：并发归档所有条目保留；复制中断、来源变化、manifest 写入失败后可恢复。

## P2：生命周期与诊断（随后）

  - 进展：归档 manifest 与文件发布在同一 run 锁内；临时文件校验后原子替换；并发归档、复制中断、manifest 失败均可恢复。
- [~] **N06 进展/停滞/恢复统一阶段规则**
  - 建议：声明 lastProgressAt/statusRequestedAt；新进展撤销旧宽限；初始化预算仅限初始化阶段；reported 必须有报告 SHA。
  - 验收：状态可持久化；新活动不被旧请求判停滞；缺报告不能接受为已验证完成。

  - 进展：新进展撤销旧宽限；终态初始化返回 not_applicable；reported 必须有 report_sha；schema 声明 lastProgressAt/statusRequestedAt。剩余：统一观察结构与压缩恢复语义。
- [~] **N07 清理与证据路径边界**
  - 建议：branch 检查归属/checkout；worktree 检查 shared/未知；持久根父链防符号链接；manifest 引用边界。
  - 验收：共享/非本 run/仍在 checkout 的资源不产生删除动作；未知不标为已移除。

  - 进展：branch 检查归属/checkout；shared worktree 保护；未知 worktree 返回 protect_unknown；`.threadweave`/`reports` 父目录符号链接拒绝。剩余：manifest 引用边界与删除前重新采集证据。
- [ ] **N08 诊断、Skill 与真实适配入口**
  - 建议：doctor 校验 schema/身份/不变量；inspect 防御异常输入；明确 state.json/state.md 关系；L14 真实适配器后置。
  - 验收：JSON 可读但结构/身份/版本有误时明确诊断，不返回健康。
