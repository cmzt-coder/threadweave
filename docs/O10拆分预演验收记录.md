# O10 拆分预演验收记录

日期：2026-11-16。证据 Run：`20261116-o10-split-preview-01`。

## 结论

O10 已完成只读拆分预演：

- 检查候选 worker 的写集冲突和未来路径重叠。
- 检查 serializedResources 资源组冲突。
- 输出契约读写依赖和多个契约写入冲突。
- 对非法声明标记 unknown，不把未知当作安全。
- 不生成综合风险分，不自动派发，不执行 merge、cleanup 或宿主调用。

## 输入

示例：`references/split-preview.example.json`

每个 worker 声明：

- `ownedPaths`
- `scopeExceptions`
- `readContracts`
- `writeContracts`

并可选传入 `serializedResources`。

## 输出

- `status`: `conflict` / `needs-review` / `no-known-conflict`
- `writeSetConflicts`
- `resourceConflicts`
- `contractConflicts`
- `contractDependencies`
- `unknowns`
- `readOnly: true`
- `autoDispatch: false`
- 固定 limitations 说明

`no-known-conflict` 只表示声明层面未发现已知冲突，不是安全评分，也不是派发授权。
