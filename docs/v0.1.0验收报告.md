# Threadweave v0.1.0 验收报告

日期：2026-11-12。
版本：`v0.1.0`（本地 tag，未发布）。
说明：本报告汇总已完成能力、真实运行证据、本地测试结果与未验证项；未取得证据的项不标为通过。

## 一、项目定位

Threadweave 是一个 Skill + Markdown 协议 + Python 参考实现，核心目标是让多个真实 Codex 线程在独立 worktree 中并行协作，并由 leader 完成初始化、派发、串行集成、报告与清理。

## 二、已完成能力

| 模块 | 内容 |
| --- | --- |
| Skill 协议 | `SKILL.md` 六阶段流程、preflight、worker 注册/启动/派发/报告模板 |
| 状态 | `references/state.schema.json`、`scripts/state_store.py`（转换校验、原子写入、文件锁） |
| 恢复 | `scripts/recovery.py`、durable 位置扫描与恢复分类 |
| 归档 | `scripts/archival.py`（report/notes 复制、SHA256 manifest、冲突拒绝） |
| 清理 | `scripts/cleanup.py`（幂等、停止证据、脏/未合并/未归档保护） |
| 工程 | `scripts/threadweave.py` CLI、`scripts/host_adapter.py`、`scripts/controller.py`、`scripts/run_log.py`、`scripts/budget.py` |
| 兼容 | `docs/宿主兼容矩阵.md`、`tests/run_all.py`、`.github/workflows/test.yml` |

## 三、真实运行证据

- 正向双 worker：A/B 真实创建、独立 worktree、初始化门禁、消息往返、提交、串行集成、报告保存与清理。
- 故障路径：不可用模型、无效 reasoning、零 projectId、取消、停滞检测、一次真实替换、managed worktree 生命周期。
- 证据位置：`.threadweave/20261112-real-dual-02/`、`.threadweave/20261112-p02-fault-01/`、`docs/第一轮执行闭环验证记录.md`。

## 四、本地测试

```bash
python3 tests/run_all.py
```

当前 12 套 smoke 测试、188 项断言通过。覆盖：

- Git 原语与静态契约
- 启动门禁拒绝条件
- 状态 schema、原子写入、锁、恢复定位
- 恢复分类、归档 manifest、清理保护
- 本地 CLI、fake adapter 控制器、JSONL 日志、预算/停滞/重试

这些测试不能替代真实 worker 冒烟。

## 五、未验证 / 受阻

- 多 projectId 匹配：需受控适配环境。
- create API 层超时：宿主 schema 无 timeout 参数。
- 隐藏 `update_plan` / `wait_threads` 环境下的运行时降级。
- 真实 worker 注入错误启动报告。
- 宿主无 replacement-count 内建限制；每角色一次替换由协议/控制器强制。
- 远程 CI 尚未实际运行（仓库无 remote）。
