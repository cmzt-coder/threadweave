# O16 宿主保护负向矩阵与最终完成度评估

日期：2026-11-17。范围：汇总 O16 已完成的本地能力、真实宿主证据和仍无法由本地代码证明的宿主边界。结论：本地可实现的 O16 功能范围已完成；完整 O16 关闭仍依赖宿主签名身份和真实 shared/protected/submodule 拒绝证据。

## 保护与身份矩阵

| 项目 | 当前证据 | 状态 | 剩余条件 |
| --- | --- | --- | --- |
| primary checkout 拒绝 | 当前实例多次真实 `archive_worktree` 返回 `The task's primary checkout cannot be removed.`，目录和附件保留 | real_host_negative_passed | 无本地剩余 |
| owner/attachment 不匹配 | 历史真实宿主返回 `This worktree is not attached to the current task.` 和 `This worktree is owned by another task.` | historical_real_host_observed | 需要当前版本重新采集完整原始回执 |
| shared 保护 | 只由 `archive_worktree` 工具声明覆盖；当前没有可制造的 shared 资源 | contract_only_blocked | 需要宿主提供真实 shared 场景 |
| workspace-protected | 只由工具声明覆盖 | contract_only_blocked | 需要真实受保护 workspace 场景 |
| submodule / embedded Git | 只由工具声明覆盖 | contract_only_blocked | 需要真实资源负例 |
| thread 附件连续性 | 修复前后 SQLite 快照：同一 thread 的 active `worktree` 变为 `archived_worktree` | local_evidence_passed | 不证明宿主签名身份 |
| 授权信封 | 计划/停止/附件/请求/授权窗口绑定通过；guard 和显式 opt-in 执行路径通过 | controlled_integration_passed | 需要预归档信封下的真实端到端验收 |
| 宿主签名身份 | 当前工具不返回签名 identity；只能读取本地 Codex thread DB | blocked_host_capability | 需要宿主提供签名身份或权威等价字段 |
