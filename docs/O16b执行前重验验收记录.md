## 门禁规则

输入：

- 已批准的计划 JSON。
- 新的 observations JSON。
- 可选 expected fingerprint。
- 最大证据年龄，默认 300 秒。

重验步骤：

1. 校验 expected fingerprint 是否等于初始计划 fingerprint。
2. 使用新 observations 重新生成当前计划。
3. 比较初始和当前计划 fingerprint。
4. 检查当前 worker 的 SAFE/REVIEW/BLOCKED 分类。
5. 检查 observations 是否更新鲜。
6. 只有无漂移且全部 SAFE 时返回 `eligible`；仍不执行删除。

返回结果包含：

- `status`: `eligible` / `review` / `blocked`
- `readOnly: true`
- `deletionPerformed: false`
- `executionApproved`
- `requiresExplicitExecutionAuthorization`
- `planChanged`
- `fingerprints.initial/current/expected`
- `classifications`
- `currentPlan`
