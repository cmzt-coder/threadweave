## 结论

O08 已实现本地契约冻结门禁：

- 从 `threadweave.config.json` 的 `stableContracts` 读取精确文件。
- 为每个契约文件记录 SHA256，并生成 canonical contractHash。
- 在报告接收和集成前重新哈希，未批准的漂移以 `contract_drift` 阻断。
- leader 批准变更时记录原因、旧/新 hash 和变更路径，清除旧报告/acceptance/verificationPlan，推进 taskRevision，要求重新派发。
- 没有 `stableContracts` 声明时保持旧行为，不宣称契约已验证。

## 配置

```json
{
  "stableContracts": ["api/schema.json"]
}
```

契约路径必须是仓库相对精确文件，不允许绝对路径、父目录、glob 或符号链接。
