## 结论

O09 已完成本地不可变制品交接实现：

- handoff manifest 绑定 run、producer role/attempt、source SHA、taskRevision、receiver、purpose、源路径、归档路径、大小和 SHA256。
- 生产文件先复制到 durable archive，再写入带内容哈希的 manifest。
- 消费者使用前校验 run、producer、receiver、purpose、archive path、size 和 SHA。
- 同名不同内容生成新的 handoff/archive，不覆盖旧制品。
- 生产文件清空或 worktree 清理后，归档仍可验证读取。
- manifest 被篡改时拒绝读取。

真实“A 产出、B 消费”的多阶段场景尚未提供，因此 O09 保持 `[~]`。

## 实际本地验证

`tests/handoff_smoke.py`：19 项。

验证：

- 正确身份与 purpose 校验。
- wrong run / producer / receiver / purpose 拒绝。
- archive 内容篡改拒绝。
- producer 删除源文件后归档仍可读取。
- 相同内容幂等，无重复破坏。
- 同名不同内容不覆盖。
- 路径穿越拒绝。
- manifest 被篡改后 hash 校验失败。

## 边界

- 本地测试使用临时文件，不是真实的 A→B worker 多阶段调度。
- 当前没有自动消费调度器；消费者必须显式调用校验接口。
- 归档目录需要由 leader 放在 durable run 目录，不能依赖生产 worktree 存活。
- 制品路径只支持精确文件；目录递归、压缩包和多模态制品尚未扩展。
