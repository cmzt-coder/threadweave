## 发现并修复的问题

1. **H01 附件类型校验缺口**：修复前混合 string/null 列表在 sorted 中抛 TypeError，Controller 不能持久化此次拒绝。现在先验证每项为非空字符串，再比较完整清单。
2. **P0 创建超时后的重复调用缺口**：修复前 lastCreateError 虽标记 unknown/non-retryable，但调用入口不检查；重启重复调用会再次进入适配器。现在当前 run 存在未核对的 create_timeout/unknown 时拒绝后续创建，拒绝不修改状态字节。

超时保护不自动声明创建失败，不自动清空未知结果，不自动重试或换模型。桌面桥接原请求的回执核对路径仍存在；本次没有为直接适配器新增自动解除冻结入口。崩溃发生在调用之前或超时结果写盘之前的完整持久意图问题，不由本轮“已保存超时状态”测试推导覆盖。
