- 显式覆盖先验证目标宿主支持情况；不可用模型与无效 reasoning 均在创建前阻塞。
- 未观察到的实际模型值记录为 `unknown`，不宣称具体模型。
- 当前 run 未使用显式模型覆盖。

## 宿主限制结论（2026-11-12）

以下不是实现缺口，而是当前宿主能力限制；已记录并在协议/控制器层采用替代或强制策略：

| 限制 | 结论 | 替代/强制策略 |
| --- | --- | --- |
| create API 超时 | 不支持 | 控制器记录 `lastCreateError`，不自动重试；需要显式重试 |
| 立即中断当前命令 | 受限 | 取消是 turn 边界 steering；等待 turn 结束、线程 idle 后确认停止证据 |
| 宿主 replacement-count | 不支持 | 控制器 `replace_worker` 强制每角色一次替换上限 |
| primary worktree archive | 受限 | 先 `handoff_thread` 切回 Local，再非强制 `git worktree remove` |
| 其他 task worktree 管理 | 受限 | 不跨 task attach/archive；保留资源并记录 |

## 可选工具降级

- `update_plan` 缺失：把六阶段计划写入 state，worker 三阶段计划写入 notes。
- `wait_threads` 缺失：使用有界状态检查与退避，记录不活动时间和宽限截止，不忙轮询。
- 不得静默替换缺失的必需能力；缺失项必须记录在状态与最终报告中。
