## 新的结论

1. 不能说问题只是终端 `pwd` 未切回主项目；
2. 宿主任务内部可能保留了“该 managed worktree 是当前 task primary”的状态；

4. 当前接口没有提供清除该任务级 primary 状态或 detach 的入口；
5. 继续重复归档不会产生新证据，反而可能造成无意义操作。

这不是 O16 正向通过，也不是普通的用户操作错误，而是当前宿主工具之间的状态一致性问题。没有执行强制删除或手动修改 Git 注册。
