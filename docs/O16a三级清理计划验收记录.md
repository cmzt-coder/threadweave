## 分类规则

### SAFE

同时满足：

- 独立验收证据通过。
- worktree 干净且无未合并成果。
- report 已归档并校验。
- thread 停止证据完整。
- worker 状态为 `idle` 或 `archived`。
- 资源属于本 run，且不是 primary/shared。
- branch 已合并、不属于其他 checkout。

### REVIEW

证据不足或不新鲜，需要重新采集/人工确认：

- `protect_unknown`
- `protect_stale`
- `protect_report`
- `protect_unverified`
- `protect_acceptance_unknown`

### BLOCKED

明确存在风险，不允许清理：

- 脏 worktree
- 未合并成果
- 活动线程
- primary/shared worktree
- 非本 run 资源
- 已检出 branch
- 已确认验收失败

## Plan 输出

每个 worker 计划包含：

- `worktree`
- `branch`
- `stop_evidence`
- `classification`
- `reasons`
- `resourceLevels`

`reasons` 保留具体保护原因，不只返回一个笼统的风险等级。计划没有任何删除副作用。
