## 配置契约

`threadweave.config.json` 的 `setup` 对象：

```json
{
  "setup": {
    "version": 1,
    "argv": ["python3", "-m", "pip", "install", "-r", "requirements.txt"],
    "cwd": ".",
    "timeoutSeconds": 900,
    "failurePolicy": "block",
    "idempotent": true
  }
}
```

约束：

- `argv` 必须是非空字符串数组，不经过 shell。
- `cwd` 必须是 worker worktree 内仓库相对路径。
- `timeoutSeconds` 独立于初始化预算，范围 1..86400。
- `failurePolicy` 只接受 `block`。
- `idempotent` 必须为 true 才允许按相同 `configHash` 复用。
- 配置不从 verify plan 自动推导，也不自动扫描/复制 `.env*`。

## Controller 行为

新增 `Controller.run_worker_setup`：

- 只允许 `pending` 或 `validating` worker。
- 相同 configHash 的成功 setup 可复用，不重复执行命令。
- 准备后重新读取 worker root、common dir、branch、HEAD 和 clean 状态。
- 失败、超时或 tracked 文件变脏时：
  - 持久化 `setupStatus=failed`
  - `setupEvidence.status=failed`
  - 追加 `workspace_setup` 来源错误
  - 阻断后续正式派发
  - 不自动重试、不自动 reset/stash/commit 用户文件
- 输出只持久化 SHA256、字节数和截断状态，不保存原始 stdout/stderr。
